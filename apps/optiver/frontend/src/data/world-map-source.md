# World outline

Derived on 3 October 2026 from Natural Earth's public-domain 1:110m admin-0 country polygons. Equirectangular projection, rounded SVG paths; Antarctica omitted. Country label points are representative country locations, **not project coordinates**. The challenge dataset supplies country names only. Circle areas represent purchased tonnes aggregated by country.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
License: https://www.naturalearthdata.com/about/terms-of-use/

Country aliases: Viet Nam → Vietnam; Türkiye → Turkey. Borders are cartographic context, not a statement about sovereignty. No external map requests at runtime.
